# 刘迷糊｜冥想手帐

版本 **1.2.0**。皮纹封面与手工纸内页的个人主页，同一网址适配电脑、平板和手机。

五个栏目：我与冥想、团体冥想、一对一冥想、正念生活、合作与培训。

## 本地预览

需要 Python 3，无安装依赖或构建步骤：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

本地打开 http://127.0.0.1:8765/ 。

固定公开网址：**https://yukinliu.github.io/mihu-meditation-journal/** 。公开网站由同一仓库的 `gh-pages` 分支托管；Release 是下载版本。地址末尾的 `#group`、`#about` 等是书内页面定位，分享主页时可省略。

## 文件与维护

- `dist/index.html`：五页正文、封面、相册与微信联系窗口。
- `dist/style.css`：响应式布局、纸面材质、页签和翻页样式。
- `dist/app.js`：一屏分页、章节内页路由、封面开合、翻页、相册及联系交互。
- `dist/assets/`：当前页面实际使用的插画、纹理、字体子集和联系二维码。
- `scripts/check.py`：发布前结构、资源引用与隐私文件检查。
- `CHANGELOG.md`：正式版本变化。

修改文案后运行检查；添加新汉字时，需确认现有字体子集覆盖，未覆盖字符将回退到系统字体。图片相册通过点击、方向键或左右滑动切换，无自动播放。开篇依次为初次见面、2013—2015、2015—2022与2023；历程地图可直接跳转。

## 验证

```sh
node --check dist/app.js
python3 scripts/check.py
```

本次发布已在本机浏览器核对封面打开、五个页签、正向及反向翻页、合上并重新打开、相册、微信弹窗；检查电脑与手机布局。翻页只移动离开的页面，下层目标页保持静止。系统偏好减少动态效果时跳过动画。

## 内容与素材

文案和插画属于个人主页发布内容；微信二维码是公开联系入口。历史图片为本人提供照片的手绘转绘或场景再创作，不将参加培训的经历写成带领活动。页面不上传私人记录，不使用分析统计或追踪脚本。

插画由内置图像工具基于本人提供素材生成；纹理由 SVG 定义。仓耳今楷字体子集保留字体内版权信息，字体权利归原权利人。仓库公开不意味着授予个人肖像、文字、插画、二维码或第三方字体的再分发许可。

旧版页面、试验脚本、未使用素材与托管试验配置已移出本仓库，不包含在正式发布包内。

1.0.0 已完成：翻页旧正文可见、下层目标页可见、公共联系区不进入翻起层、五栏目路由、返回封面、相册切换、图片加载与联系窗口检查。手机与平板规则保留，尚未逐设备实机验收。

## 一屏分页与发布

五个页签只表示章节入口；经历、研究、服务流程等使用无页签内页。脚本按视口可用高度将长内容续到下一张纸，手机可比电脑分出更多页。封面关闭时隐藏装订和索引，打开后页签嵌在页缘。

正文在 `dist/index.html` 与 `dist/app.js` 的开篇文案中维护，`dist/app.js` 中的页面分组决定哪些段落组成一张语义内页。皮纹 `cover-leather.png` 为根据材质参考生成的纯纹理，不含用户提供的实拍参考照片。

发布时先核对源码，再从 `dist/` 生成纯静态发布分支及下载包；保持现有 Pages 地址和仓库名不变。
